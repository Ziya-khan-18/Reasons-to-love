# ETERNAL — 365 Reasons

A cinematic interactive website built as a digital “365 Reasons Why I Love You” jar.

This project creates an emotional experience just for my special one: Nir, where a he opens one note each day from a glass jar filled with 365 fragments. Each fragment reveals a reason written from the heart.

The site combines storytelling, motion design, and interaction to transform a simple message into a year-long journey.

# Concept

The idea is simple:

There are 365 reasons inside a jar.

Each day the he clicks the jar and extracts one fragment, revealing a message.

When all fragments are opened, the jar glows and a final message appears.

Then the jar refills itself, allowing the journey to begin again.

This mirrors the idea that love does not run out of reasons.

# How It Works

When the jar is clicked:

The jar shakes slightly.

A fragment animates out of the jar.

A note card appears.

One reason is revealed.

The remaining counter decreases.

When the final fragment is opened:

The jar glows bright emerald.

The interface fades.

A final message appears.

After a few seconds the jar refills.
